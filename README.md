# Mộc Nhiên — Landing page

Landing page mẫu bằng HTML và SCSS, gồm navigation/header, giới thiệu thương hiệu, sản phẩm nổi bật, số liệu thống kê và footer responsive.

## Chạy dự án

Yêu cầu Node.js và npm.

```bash
npm install
npm run build:css
```

Mở `index.html` trên trình duyệt. Mã SCSS nằm trong `scss/styles.scss`; CSS dùng cho trang được biên dịch ra `css/styles.css`.

Khi chỉnh sửa SCSS và muốn tự động biên dịch:

```bash
npm run watch:css
```

Ảnh minh họa và font chữ được tải từ Unsplash và Google Fonts.
